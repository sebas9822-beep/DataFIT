## Condiciones para activar uno (concepto del buscador de predios)

1. Ficha de viabilidad aprobada: términos de uso, `robots.txt`, existencia de API o convenio.
2. Sin evasión: ante un 403, un 429 o un CAPTCHA la fuente se detiene y queda como `bloqueado`.
3. Sin datos personales: nombres, teléfonos y correos de anunciantes no se guardan.
4. Precio marcado siempre como `pedido`.

Mientras tanto, la referencia de oferta es la capa histórica del OIME (ver `oime_ofertas.md`).
